# Universal Animation Library, root motion

`UAL1_Standard_RM.glb` is the root-motion variant of the Quaternius Universal Animation
Library 1, with its own mannequin. It carries 43 clips; the locomotion ones the demo needs
are `Idle_Loop`, `Walk_Loop`, `Jog_Fwd_Loop`, `Sprint_Loop` and `Crouch_Fwd_Loop`, and their
root joint moves forward by 0, 1.30, 5.00, 5.50 and 1.50 units per cycle.

The rig names the bones `root`, `pelvis`, `spine_01`, `head`, `hand_l`, `hand_r`, `foot_l`
and `foot_r`, so it matches `Schema.locomotion` as it is; the root motion lives on `root`.

Source: <https://quaternius.itch.io/universal-animation-library>, CC0 1.0, taken from
<https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender>.
