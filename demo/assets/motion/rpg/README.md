# RPG Animations, root motion

`Unarmed_RM.glb` is the root-motion build of RPG Animations GLB FREE 0.1.0, a character with
64 clips: `UnarmedRunForward`, `UnarmedSprint`, `UnarmedStrafeLeft`, `UnarmedStrafeRight`,
`UnarmedStrafeForward`, `UnarmedStrafeBackward`, the diagonals, turns and actions.

The root motion lives on the node `Motion`; the body bones are named `B_Pelvis`, `B_Head`,
`B_L_Hand`, `B_R_Hand`, `B_L_Foot` and `B_R_Foot`, and the model is authored in centimetres
(180 units tall), so the demo scales it by about 0.01.

Source: <https://store.godotengine.org/asset/explosive-llc/rpg-character-animations-pack-free/>,
which is also published at <https://www.explosive.ws/products/rpg-animations-glb-for-godot-blender>;
the free version, taken on 2026-11-03.
